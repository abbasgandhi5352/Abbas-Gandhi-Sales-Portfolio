ABBAS GANDHI — PERSONAL PORTFOLIO WEBSITE

Preview locally:
1. Extract the ZIP file.
2. Open index.html in a browser. An internet connection is required for the Google Fonts.

Publish with GitHub Pages:
1. Create a new GitHub repository (or open the repository you want to use).
2. Upload index.html and the complete assets folder to the repository root.
3. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
4. Wait for GitHub Pages to publish the site.

Before publishing, verify that the public phone number, email, LinkedIn URL, work-history wording and achievements are correct. The WhatsApp button opens a chat with +91 70167 05053.

The website is static HTML/CSS/JavaScript and does not require a server or build process.
